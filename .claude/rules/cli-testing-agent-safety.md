# CLIエージェント安全性テストルール

エージェント特有の入力ミスをファズテストで検証する。

## 必須実装

### ファズテスト対象

以下のエージェント典型ミスを入力としてテストする:

1. **パストラバーサル**: `../../etc/passwd`, `../../../.ssh/id_rsa`
2. **クエリパラメータ埋め込み**: `resourceId?fields=name&limit=1`
3. **二重エンコード文字列**: `%2F`, `%252F`
4. **制御文字**: `\x00`, `\x1f`, null バイト
5. **超長文字列**: 10,000文字超の入力
6. **不正なJSON**: 閉じ括弧なし、トレーリングカンマ

### dry-runテスト

- 全変更操作の `--dry-run` が実際のAPI呼び出しをしないことをテストする
- dry-run出力が実行予定の内容を正確に反映することをテストする

### 出力形式テスト

- `--output json` の出力が常に有効なJSONであることをテストする
- エラー時のJSON出力が一貫したスキーマであることをテストする
- exitコードがドキュメントと一致することをテストする
