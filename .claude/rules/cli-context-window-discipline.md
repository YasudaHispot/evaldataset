# CLIコンテキストウィンドウ規律ルール

APIレスポンスは巨大になりうる。エージェントはトークンごとに課金され、不要なフィールドで推論能力が低下する。

## 必須実装

### フィールドマスク

- `--fields` フラグで返却フィールドを制限可能にする
- デフォルトで全フィールドを返さず、よく使うフィールドのサブセットをデフォルトにすることを検討する

```bash
# 使用例
mycli files list --fields "id,name,mimeType"
```

### ページネーションのストリーム対応

- `--page-all` でNDJSON形式の全ページ取得を提供する
- 1ページごとに1JSONオブジェクトを出力し、トップレベル配列のバッファリングを避ける
- エージェントがストリーム処理できるようにする

### レスポンスサイズ制御

- `--limit` や `--max-results` でレスポンスの件数を制限可能にする
- 巨大レスポンスに対する警告またはデフォルト上限を設ける
