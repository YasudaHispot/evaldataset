# CLIエージェントスキルファイルルール

人間はヘルプやドキュメントで学ぶ。エージェントは会話開始時に注入されたコンテキストで学ぶ。`--help` だけでは伝わらない不変条件をスキルファイルに記述する。

## 必須実装

### CONTEXT.md / スキルファイルの提供

- CLIに付随する `CONTEXT.md` またはスキルファイル（YAML frontmatter + Markdown）を作成する
- エージェントが `--help` からは推測できない暗黙のルールを明文化する

### スキルファイルに記述すべき内容

```yaml
---
name: mycli-operations
version: 1.0.0
metadata:
  requires:
    bins: ["mycli"]
---

# mycli エージェント操作ルール

## 必須ルール
- 変更操作の前に必ず `--dry-run` を実行すること
- ユーザーに確認を取る前にwrite/deleteコマンドを実行しないこと
- listコマンドには必ず `--fields` を付与してレスポンスサイズを制限すること
- エラー時は `--output json` の出力をそのまま報告すること

## 推奨パターン
- 複数リソースの操作はバッチではなく逐次実行する
- 不明なリソースIDは操作前に `get` で存在確認する
```

### スキルファイルのコスト正当性

- ハルシネーションからのリカバリコスト > スキルファイルの注入コスト
- エージェントが暗黙知を推測する必要をなくすことが目的
