ユニットテスト（UT）の作成と実行を行います。

## 作業手順

### 1. 対象の特定

- 引数でファイルやモジュールが指定されている場合はそれを対象とする
- 指定がない場合は、直近の変更（`git diff`）からテスト対象を特定する

### 2. 仕様の確認

- `docs/design.md` を読み、対象コンポーネントの設計を理解する
- `src/evaldataset/` の対象コードを読み、インターフェースと実装を理解する

### 3. テスト作成

- **配置先**: `tests/unit/`
- **命名**: `test_<module_name>.py`
- **モック使用**: 許可（`docs/mock-policy.md` のユニットテスト項参照）
- **カバレッジ**: 関数・分岐を網羅する

テスト作成時の観点:
- 正常系: 主要な入出力パターン
- 異常系: エラーハンドリング、例外
- 境界値: 閾値、空入力、最大値
- エッジケース: Unicode、特殊文字、巨大データ

### 4. テスト実行

```bash
uv run pytest tests/unit/ -v
```

### 5. 結果報告

- 全テストがパスした場合: テストファイルとカバレッジを報告
- 失敗がある場合: 失敗内容を分析し、テストまたは実装の修正を行う
