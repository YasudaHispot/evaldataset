description: "実装タスクを開始します（ブランチ作成まで）"
---

手動で実装する際のタスク開始コマンド。ブランチ作成とspec確認までを行い、実装はユーザーに任せる。

1. `CLAUDE.md` を読み、プロジェクトのルールと方針を確認する。
2. `gh issue list --label task --state open` で未完了タスクを取得する。
3. 最新のmainブランチを取得する。未コミットの変更がある場合は、メッセージを表示して処理を中断する。
4. **次の最も若い番号の**未完了タスク1つに対して、タスク用のブランチを作る。
   ブランチ名: `task{n}` (n:タスク番号)
5. 対象タスクの受入条件（Given/When/Then）が `docs/design.md` に存在するか確認する。
   - 存在しない場合: `/create-spec` で受入条件を作成する。
   - 存在する場合: スキップ。
6. タスクの内容（Issue本文、受入条件）を表示して完了する。

**注意**: このコマンドは実装を行わない。実装はユーザーが手動で行うか、`/continue-task` で自動実行する。
実装完了後は `/end-task` でPRを作成する。
