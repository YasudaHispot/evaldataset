---
description: "実装タスクを終了します（commit + push + PR作成）"
---

手動実装の完了後にPRを作成するコマンド。

1. 現在のブランチがタスク用ブランチ（`task{n}`）であることを確認する。
   - 違う場合はエラーを報告して終了する。
2. `uv run pytest tests/ -v` で全テストが通ることを確認する。
   - 失敗する場合はエラーを報告して終了する。
3. 未コミットの変更があれば、適切なメッセージでcommitする。
4. リモートにpushする。
5. `gh pr create` でPRを作成する。タイトルにタスク番号とチェッカー名を含める。
6. PR URLを報告する。

**注意**: このコマンドはレビューを行わない。レビューが必要な場合は `/team-review` を別途実行する。
