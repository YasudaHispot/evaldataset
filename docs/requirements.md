# 要求仕様書

## 目的

CPT（Continued Pre-Training）用 のArrow・Parquet形式のデータセットの品質を自動チェックし、問題を検出・修正するCLIツールを提供する。

## 対象ユーザー

- LLMの継続事前学習用データセットを準備するMLエンジニア

## 機能要件

- データセット読み込み
- 構造チェック
- テキスト品質チェック
- 重複検出
- コンテンツ品質チェック
- 自動修正
- レポート出力
- 設定ファイル、オプション

## 非機能要件

### NFR-01: パフォーマンス

- 100万行規模のデータセットに対して実用的な時間内に完了する
- `--sample-size` でサンプリングによる高速チェックが可能

### NFR-02: 拡張性

- 新しいチェッカー、Fixer を追加可能に

### NFR-03: エージェント親和性

`.claude/rules/cli-*.md` に定められたCLI設計原則を遵守すること。
